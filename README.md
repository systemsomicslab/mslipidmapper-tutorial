# MSLipidMapper Tutorial

An English-language tutorial site for MSLipidMapper, maintained independently of the application repository.

## Local preview

Open `index.html` in a browser. The site requires no dependencies or build step.

## Publish with GitHub Pages

Add the contents of this directory to a dedicated repository, such as `systemsomicslab/mslipidmapper-tutorial`. In **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, and save.

With that repository name, the published site will be available at https://systemsomicslab.github.io/mslipidmapper-tutorial/.

## Maintain the tutorial

Each chapter has its own HTML file in the repository root. Shared styles are in `assets/site.css`. The application screenshot comes from `docs/MSLipidMapper.png` in the application repository. The instructions and sample data reference application commit `178a6e9c1d9c809c4e57834aca4fce86e7451503`. When updating the tutorial for a new version, review the instructions, screenshot, and links together.
