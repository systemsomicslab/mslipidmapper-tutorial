Installation and setup

Run MSLipidMapper as an R package or in a Docker container.

Run as an R package

Install R 4.3 or later, then run the following commands in the R console.

install.packages(c("BiocManager", "remotes"))
BiocManager::install(c(
  "SummarizedExperiment", "S4Vectors", "ComplexHeatmap",
  "clusterProfiler", "GO.db", "ropls", "rgoslin"
), ask = FALSE, update = FALSE)
remotes::install_github("systemsomicslab/MSLipidMapper", dependencies = TRUE)
MSLipidMapper::run_mslipidmapper()

Once the app starts, open http://localhost:3838 in your browser.

Run with Docker

Start Docker Desktop or another Docker runtime, then run these commands in a terminal.

git clone https://github.com/systemsomicslab/MSLipidMapper.git
cd MSLipidMapper
docker build -t mslipidmapper .
docker run --rm -p 3838:3838 -p 7310:7310 mslipidmapper

Open http://localhost:3838 in your browser. On Windows, you can also build and launch the container with the included MSLipidMapper.bat file.
